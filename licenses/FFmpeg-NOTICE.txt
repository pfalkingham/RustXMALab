FFmpeg (libswscale): copyright and licence
==========================================

RustXMALab contains no FFmpeg code and does not ship FFmpeg; it can run the ffmpeg and
ffprobe programs installed on the machine (see NOTICE.md). To give the grey values the C++
XMALab gets from OpenCV and FFmpeg, crates/xma-video/src/ffmpeg/grey.rs reproduces the
luma expansion of libswscale's default YUV to RGB conversion (limited-range luma expanded
as clip((76309 * (Y - 16) + 512) >> 16)).

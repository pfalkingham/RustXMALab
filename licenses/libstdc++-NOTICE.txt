libstdc++ (GCC): copyright and licence
======================================

Code ported from: the sorting algorithm of GNU libstdc++ (std::sort: introsort with a
heapsort fallback and a final insertion sort, bits/stl_algo.h and bits/stl_heap.h), in
crates/xma-vision/src/linalg.rs, so that cv::sortIdx orders equal keys as the C++ XMALab
does.
